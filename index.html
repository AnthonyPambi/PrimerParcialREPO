Bienvenido a Dolarito

Tus finanzas personales y familiares, claras y bajo control, desde tu celular.

Dirigido por Anthony Pambi

Sobre el proyecto

Dolarito es una aplicación móvil desarrollada en Flutter que permite gestionar tus finanzas personales de manera eficiente y sencilla. Con Dolarito puedes llevar el registro de tus ingresos y gastos, establecer presupuestos y consultar informes detallados de tu situación financiera.

¿Necesitas ayuda con tus finanzas?

Una aplicación para organizar tu dinero y el de tu familia sin complicaciones.

Beneficios

Cuenta
Reúne tus saldos y movimientos en un solo lugar, para ti o para todo tu grupo familiar.
Tarjetas
Registra tus tarjetas y revisa cuánto gastas con cada una.
Gastos
Anota cada ingreso y gasto, y mira en qué se va tu dinero.
Ahorro
Define metas y presupuestos, y sigue tu avance mes a mes.

Stack tecnológico

Aplicación móvil

Flutter
Framework para crear la aplicación móvil con un solo código.
Dart
Lenguaje de programación con el que funciona Flutter.
MVVM + Repository
Organización del código en capas, con datos que también funcionan sin conexión.

Página web

HTML
Lenguaje de marcado para estructurar el contenido de la web.
CSS
Lenguaje de estilo para definir la apariencia de la web.
JavaScript
Lenguaje de programación para agregar funcionalidad interactiva a la web.
PHP
Lenguaje del lado del servidor para procesar datos y generar contenido dinámico.
